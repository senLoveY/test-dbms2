# test-dbms2

Простой сайт для прохождения теста по MS SQL Server (20 вопросов из файла `ответы.pdf`).

## Запуск

Откройте `index.html` в браузере.

## Что реализовано

- 20 вопросов с вариантами ответов.
- Поддержка одиночного и множественного выбора.
- Проверка, что все вопросы заполнены.
- Вывод выбранных ответов после завершения попытки.
- Счетчик завершенных попыток в `localStorage`.
