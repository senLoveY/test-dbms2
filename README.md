# test-dbms2

React-приложение для прохождения теста по MS SQL Server (20 вопросов).

## Запуск

```bash
npm install
npm run dev
```

Откройте URL из консоли Vite (обычно `http://localhost:5173`).

## Что реализовано

- Современный интерфейс на React + Vite.
- Режим прохождения: на экране только один вопрос.
- Поддержка single choice и multiple choice.
- Кнопки навигации вперед/назад и индикатор прогресса.
- После завершения:
  - итоговый балл;
  - подробный разбор всех вопросов;
  - подсветка правильных, пропущенных правильных и ошибочно выбранных вариантов.
